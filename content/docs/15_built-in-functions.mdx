# Built-in Functions in Soplang

Built-in functions are available without imports. They cover printing, user
input, type inspection and conversion, collection creation, numeric operations,
and ranges. Soplang 3.6 also provides `khalad`, `xirmo`, `urur`,
`sug`, channels, file and network functions, and bundled modules. See the
[3.6 overview](/docs/21_soplang-3-6) and [full reference](https://github.com/soplang/soplang/blob/v3.6.0/docs/language/keywords.md)
for their arguments and behavior.

## Notes

- **`walax()`** accepts alternating key-value arguments, such as `walax("magac", "Ali", "da", 20)`. An object literal is often simpler: `{magac: "Ali", da: 20}`.
- **`dherer()`** works on strings, lists, and objects. All three also support a `.dherer()` method.
- **`xul()`** supports three forms:
  - `xul()` returns a random floating-point number in `[0, 1)`.
  - `xul(a, b)` returns a random floating-point number in `[a, b)`. For an integer from `1` through `6`, use `daji(xul(1, 7))`.
  - `xul(list)` returns one randomly chosen list item.
- **`baaxad()`** creates a list of integers, excluding the stop bound: `baaxad(5)` produces `[0, 1, 2, 3, 4]`, `baaxad(2, 6)` produces `[2, 3, 4, 5]`, and `baaxad(1, 10, 2)` produces `[1, 3, 5, 7, 9]`.
- **`daji()` / `kor()`** return `abn` values.

## Numeric Helpers in Soplang 3

| Function | Description | Example |
| --- | --- | --- |
| `duub(x)` | Round to the nearest integer, with ties away from zero | `duub(-2.5)` returns `-3` |
| `sugan(x)` | Return the absolute value | `sugan(-5)` returns `5` |
| `yar(...)` | Return the smallest numeric argument | `yar(4, 2, 8)` returns `2` |
| `weyn(...)` | Return the largest numeric argument | `weyn(4, 2, 8)` returns `8` |
| `jibbaar(a, b)` | Raise a number to a power | `jibbaar(2, 3)` returns `8` |
| `xidid(x)` | Return the square root | `xidid(9)` returns `3` |

<SoplangCodeWindow title="numeric_helpers.sop" code={`qor(duub(-2.5))       // -3
qor(sugan(-5))         // 5
qor(yar(4, 2, 8))      // 2
qor(weyn(4, 2, 8))     // 8
qor(jibbaar(2, 3))     // 8
qor(xidid(9))          // 3`}/>

`xul()` and `xul(a, b)` exclude the upper bound. Passing an empty list to
`xul(list)` produces an error. `baaxad()` accepts integers only and rejects
a zero step. Each function validates its argument count.
General file I/O, HTTP, and network functions remain planned work.
