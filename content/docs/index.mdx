**Soplang** (Somali Programming Language) is a free, open-source programming language whose keywords are Somali words: `qor` prints, `haddii` means *if*, and `hawl` defines a function. It was created by Sharafdin Yusuf, first released in October 2023, and is developed and maintained by [Somast](https://www.somast.so/).

These docs cover everything from installation to classes, modules, and error handling.

These docs target **Soplang 3.0.1**, the Rust compiler with Cranelift JIT and LLVM standalone builds. See [Migrating to Soplang 3](/docs/20_migrating-to-v3) for compatibility and behavior changes.
